# 基线人工验收（尚未执行）

目的：补齐合成录音不能证明的人声、回声、噪声、来源语义与官方网络证据。不需提供真实商家信息或向真实号码外呼。

1. 使用部署说明启动真实模式，确认三个模型健康。佩戴耳机，用本人自然语音完成身份、沟通意愿、整改承诺、结果确认四轮；导出会话记录。
2. 在助手说明中途说“等一下，我说错了”，确认助手及时停声，旧音频不复活，未确认结果不写成同意。
3. 分别测试错人、拒绝沟通、忙需回电、要求人工、保证通过追问、无依据的问题；检查回执与实际听到的话一致。
4. 分别使用安静环境、实际背景噪声、外放回声，至少记录每种条件下的成功、失败与原始延迟，不能只保留成功录音。
5. 由另一名团队成员核对可见主表和 QA 映射，记录 reviewer_alias、来源文件哈希和条目结论。禁止把 3 个隐藏表自动纳入现行规则。
6. 按赛题组确认的方法测量用户说完至实际首字出声，报告原始样本、P50、P95；浏览器调度或模型首包不能替代声学验收。
7. 向赛题组确认校外访问校园服务器的许可路径和官方 Mock 工具契约。在确认前只做校园研发，不自行建立赛场穿透代理。

所有证据使用合成业务信息。录音、数据库、企业资料与秘密配置保留在受控且 Git 忽略的目录。填写 deploy/acceptance.pending.json 时必须附实际证据位置，不以口头“通过”代替。
