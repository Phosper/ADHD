# ADR 0002 首批实现接口与依赖

日期：2026-11-08。状态：首批文本测试通过，实时链路待完成。

共享接口以 Pydantic 模型为单一来源，生成 JSON Schema 与 OpenAPI JSON，替代规划中手写 YAML，避免多份契约漂移。CI 重新生成后检查差异。

小型知识库先采用可审查的中文字符二元组 BM25 实现，不额外依赖 rank_bm25；算法与检索边界保持原设计，未核对条目不进入检索。后续质量评测决定是否更换实现。

在未接入真实模型前，只有显式 Mock 模式使用规则意图解析器；真实模式必须在适配器就绪后开启，禁止静默降级成 Mock 并报告成功。

Python 项目使用 uv.lock 锁定，语音模型环境独立。A100 环境名称将在部署配置中按实际 A800 修正，既有设计保留历史。
