# ADR 0005 语音首包与预热

日期：2026-11-08，状态：实施与测量中。

真实 CosyVoice 首包小测 2.7—7.7 秒，尚不能达到基线门槛。核对锁定源码发现 CosyVoice2Model 在 stream=True 中修改实例的 token_hop_len，每句结束不会复位。每次合成前恢复官方初始值 25，保留其训练分块边界，不任意减小分块。

固定话术允许提前真实模型合成并缓存。缓存键含模型文件清单、参考录音、参考文本和合成文本哈希；仅完整生成后原子保存。响应头和会话 tts.generated 记录 live-model 或 model-cache。缓存仅影响发声速度，不提前决定商家身份、意愿、工具结果；不按测试 ID 特判。

冷启动、热启动及缓存命中测量分开报告。对话新内容仍实时生成，不能用缓存成绩声称任意问题都在 2 秒内。官方测量口径和人声验收仍待确认。
