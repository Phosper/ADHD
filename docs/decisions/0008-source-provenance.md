# ADR 0008：源码包内置来源清单

日期：2026-11-08。状态：已实现，团队评审待办。

独立源码包不含 .git，若解压在另一个仓库下，普通 git rev-parse 会误取父仓库提交。每通会话因此可能绑定错误版本。

源码打包时加入 .source-manifest.json，记录打包提交和包内每个普通文件的 SHA-256。运行时优先核对这份清单；改动、缺失或新增业务代码均标记 dirty。开发检出则确认 Git 根就是当前项目，并记录当前受跟踪文件摘要；没有证据时标记 unknown/unverified，不能借用父目录版本。

清单是完整性与来源记录，不是密码学签名；交付仍应核对旁置归档 SHA-256。不能据此宣布人工、网络或官方验收通过。与依赖锁、模型清单及知识哈希一起记录，不包含私密内容。
