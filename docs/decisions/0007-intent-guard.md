# ADR 0007 模型提案后的保守语义守卫

真实开发测试发现“知道了”被 Qwen3 误分为 question、覆盖指令被分为 refuse。为了不把确认知悉、操纵指令解释为业务授权，领域层统一把仅知悉的常见短句和系统规则覆盖请求约束为 unknown；接下来要求明确确认，达到重试限额才转人工。

真实模型仍执行分类；该守卫适用于所有业务场景和 Mock，不按评测用例 ID 特判。明确“我知道了，我愿意补齐重新提交”保留有效承诺。服务事件 intent.validated 明确是模型提案与守卫后的结果。守卫不是完整提示注入检测器，仍需独立语义与合规复核。

此变更来自开发集失败，只能用于开发回归；独立验收集不得复用为声称未见数据成绩。
