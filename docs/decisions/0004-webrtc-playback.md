# ADR 0004 可取消的浏览器播放

日期：2026-11-08。状态：实现中，真实浏览器与模型联调待测。

保留 Pipecat SmallWebRTC 输入音轨与 Silero VAD；输出使用同一 WebRTC 的可靠有序数据通道发送 PCM，每包带 generation_id 和序号。浏览器 AudioContext 播放，各播放节点属于唯一回复代号；打断时停止并释放全部旧节点，忽略迟到旧包。无需额外音频服务器或外网中继。代价是可靠数据通道丢包时有队首阻塞，须在校园网下实测时延；不能预先声明优于 RTP。

发送端按音频时长节流，浏览器最多排队 3 秒；队列失控、序号错误、缺少尾包或模型错误时显式结束，不把截断的音频记为完整播放。生成事件、浏览器开始/停止/完成回执、商家文本确认、工具提交分别记录。

浏览器 AudioContext 回执是软件播放证据，不能证明扬声器实际出声或用户听懂。官方端到端时延仍需录音/回环或官方测量方法；默认报告保留空值。服务器 VAD 事件明确标记 server，不伪装成客户端时间戳。
