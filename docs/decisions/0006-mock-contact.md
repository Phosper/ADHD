# ADR 0006 未接通与跟进模拟

日期：2026-11-08。

官方 Mock 接口尚未发放，使用本项目 SQLite 事务模拟结果回写和人工跟进待办。未接通是独立 contact.no_answer 事件，不伪造商家发言；只允许尚无轮次的身份阶段提交。首次/第二次重试按既有 contact_policy 处理，身份保持 unknown，不披露整改详情。

Outcome 新增 recommended_channel 和 followup_id，采用默认值保持旧记录可读取。跟进待办和结果同事务持久化，状态 pending_human；操作 ID 可通过父回执追查，不声称已经安排真实电话。请求幂等及单据版本检查沿用既有机制。接通语音期间禁止标记未接通。

此接口是研发模拟，retry_attempt 由受控操作员传入，真实次数和预约权限待官方接口对接后核实；不能用客户端模拟标记绕过真实生产策略。
