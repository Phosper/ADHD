# ADR 0001 基线模块边界与审计原则

状态：规划采用，待实现验证。日期：2026-11-07。

背景：用户确认基线设计，要求多人协作、每次对话可查及可回退；GPU 位于仅校园网 SSH 可达的服务器。

决策：单仓库、独立模块负责人、共享契约先行；纯业务核心不依赖模型和传输。API 为业务持久化唯一写入方，Voice 处理实时音频，模型使用独立进程。先 Mock 后 A100，保持同一业务契约。

记录：开发对话摘要进 Git，业务原始会话与数据保存在受控目录，发布 manifest 关联全部版本。代码回退、数据库恢复和业务补偿分开处理。

影响：前期增加契约和测试工作，减少后期前后端字段不一致、模型依赖冲突和多人覆盖文件。仅校园网可达不能作为比赛就绪证据。

重新评估条件：实际单会话时延不足、官方接口强制其他协议、服务器网络无法支持现场部署。变更通过后续 ADR 说明替代关系，不抹除旧决策。
