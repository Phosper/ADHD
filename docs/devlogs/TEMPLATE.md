# 开发对话记录

- 记录 ID：时间与唯一后缀
- 时间：开始/结束，Asia/Shanghai
- 参与者：实际成员或助手，不虚构
- 任务与分支：
- 起始 commit：
- 起始工作区：干净或已有修改及归属
- 状态：进行中/完成/中断/受阻

## 需求与决定

用户需求摘要、已确认约束、尚待确认事项。区分事实与假设。

## 实际变更

文件、目的、影响；无业务代码变化时明确说明。

## 验证证据

检查方法、结果、证据位置；未执行的检查及原因。

## 交付与回退

结果提交：包含本日志的提交，或后续提交/PR 引用。
查询：git log --all -- 本日志路径。
回退对象、依赖与方法；业务副作用是否发生；保留审计记录。

## 待办与交接

下一步、负责人、阻塞和未完成事项。
