# 开发对话日志

每次项目对话一个文件；纯讨论也记录，不要求改变业务代码。使用 [模板](TEMPLATE.md)，按日期目录保存，文件名加唯一后缀避免多人冲突。

- [历史决策补录](2026-11-07/history-summary.md)：根据当前聊天补录，不是逐字记录，早期版本无独立 Git 快照。
- [本次项目规划](2026-11-07/2303-project-planning-01a1b66e.md)：团队协作、目录、日志和回退。

后续按文件名查询即可，不要求每个人同时修改本索引。提交与日志通过日志路径关联，查看命令：`git log --all -- docs/devlogs/`。日志中严禁凭据、企业原始数据全文和真实用户信息。
