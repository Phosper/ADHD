# tau2-bench 与 τ-Voice 的来源和用途

**tau2-bench 是对话 Agent 的公开评测项目，τ-Voice 将相关任务扩展到语音交互。** 在智语外呼项目中，主要借鉴它们组织用户、Agent、业务环境和结果校验的方式，作为 Skill 自优化与经验记忆共同的评测参考。

## 原始来源

- τ²-bench 论文：[τ²-Bench: Evaluating Conversational Agents in a Dual-Control Environment](https://arxiv.org/abs/2506.07982)；本目录附有 [PDF 原文](../论文/tau2-bench.pdf)。
- τ-Voice 论文：[τ-Voice: Benchmarking Full-Duplex Voice Agents on Real-World Domains](https://arxiv.org/abs/2603.13686v1)；本目录附有 [PDF 原文](../论文/tau-Voice_2603.13686v1.pdf)。
- 作者公开代码及语音扩展入口：[sierra-research/tau2-bench](https://github.com/sierra-research/tau2-bench)。
- 本次适配分析参考的代码版本：[033bf082f48e](https://github.com/sierra-research/tau2-bench/commit/033bf082f48e4a3c6a1256208e93cf2ce9c3bb6f)。
- 下载方式：需要运行时，进入上游代码网页选择 `Code → Download ZIP`，或取得上述固定提交；安装、模型接口和数据要求按上游说明核对。本目录不存放源码或 ZIP。

## 为什么选它作参考

普通对话评价容易只看“回答像不像客服”。τ²-bench 将用户行为和任务环境联系起来，可以检查动作是否真的改变了业务状态。τ-Voice 进一步把语音交互、轮次与任务完成放在同一框架中，适合提醒我们区分文本能力和真实语音表现。

这些项目的任务、数据和模型结果属于原作者的实验，不能直接当作智语外呼系统的成绩。

## 在我们项目中具体做什么

| 可借鉴部分 | 在 ADHD 中的对应工作 |
| --- | --- |
| 任务与环境组织 | 定义合成资审案件、允许动作、初始状态和正确最终结果 |
| 受环境约束的用户模拟 | 让模拟商家按设定身份、实际意愿和可见信息回应，避免随意泄漏答案 |
| 结果校验 | 核对 Mock 回执的字段、前置确认、是否重复写入，以及拒绝或转人工是否正确 |
| 文本与语音对照 | 在相同业务任务上比较文字、合成语音、自然语音与噪声条件 |
| 过程记录 | 保存输入、动作、状态变化和候选版本，定位改进或失败来自哪里 |

ADHD 已有状态机、Mock 数据库和会话事件，可以复用这些基础，不必为了采用评测框架替换整套系统。需要新增本项目任务定义、独立评分和候选执行适配。

## 适配边界

航空、零售、电信或银行领域的规则不能直接成为资审业务答案。本项目的案件真值要由业务复核确认，最终封存测试不能参与优化。语音效果还需按比赛要求测量，软件调度时间不能代替实际出声证据。

当前仅作来源与方法参考，尚未运行该框架、移植其业务域或宣称完成语音验收。
