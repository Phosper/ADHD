# MemRL 的来源与用途

**MemRL 根据任务反馈更新经验的效用，并在检索时同时考虑相关性和效用。** 它适合参考经验记忆副线中的“用哪条经验”。

## 原始来源

- 论文：[MemRL: Self-Evolving Agents via Runtime Reinforcement Learning on Episodic Memory，v2](https://arxiv.org/abs/2601.03192v2)；本目录附有 [PDF 原文](../论文/MemRL_2601.03192v2.pdf)。
- 作者公开代码：[MemTensor/MemRL](https://github.com/MemTensor/MemRL)。
- 本次适配分析参考的代码版本：[c1b322ca43de](https://github.com/MemTensor/MemRL/commit/c1b322ca43de36ddf64c6712f89d0095bfc35ce0)。
- 下载方式：进入代码网页选择 `Code → Download ZIP`，或取得上述固定提交。运行配置、依赖与许可证见仓库说明。

## 在我们项目中做什么

当经验增多后，只按文字相似度检索，可能选到看起来相关但没有帮助的建议。可以参考 MemRL 的两阶段选择：先找到相关经验，再利用任务反馈估计的效用筛选。

本项目进一步要验证：经验伴随任务成功，是否真的意味着它带来了收益。可以按场景、阶段和规则版本比较使用与不使用经验的差异，研究什么时候该停用经验。这属于待验证的方法方向，不是现成结果。

## 需要适配什么

原仓库有记忆服务、检索器和多个任务的运行入口。接入 ADHD 仍需定义经验格式、状态到检索请求的转换、业务反馈和版本记录。原业务知识库继续只保存已审核规则，不能与自动生成的经验混成同一权威来源。

应与无记忆、固定少样例、只按相似度检索等方法比较，并控制输入长度与时延。最终测试默认冻结记忆；若研究在线更新，需单独约定可用反馈。当前没有运行该项目。
