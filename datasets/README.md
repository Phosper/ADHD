# 情绪对抗数据集清单

本目录整理客服语音助手“情绪对抗 / 安抚 / 语速调节”方向可用的公开数据集与获取方式。复核日期：2026-11-08。

## 先说结论

- **没有找到可公开下载的“中文客服情绪对抗 / 降级”语音库。**
- 中文带语音首选 **EmotionTalk + M3ED**；**MER2023 / MER2024** 做鲁棒性和跨域评测；**ESD + EMOVIE** 做声学、韵律和语速；**CSEU-Bench** 做细粒度中文语音情绪理解。
- **ESConv、CPED 是纯文本**，只能用于策略标签、中文话术和文本情绪辅助；不能当声学语料，也不能用来定语速阈值。
- JDDC 最贴客服业务，但**没有音频、没有情绪标签**；JDDC 1.0 无官方公开下载，2.1 需单位申请。

## 快速选择

| 目标 | 首选 | 备选 / 说明 |
| --- | --- | --- |
| 双人对话中的愤怒/冲突 | EmotionTalk | M3ED；都是影视/自然对话，不是客服 |
| 多轮上下文情绪 | M3ED | MER2023 / MER2024；影视域 |
| 噪声、跨剧集、开放词表评测 | MER2023 / MER2024 | 需 EULA，CC BY-NC 4.0 |

| 细粒度中文语音情绪 | CSEU-Bench | 83 类标签，不是客服 |
| 安抚策略标签 | ESConv | 英文纯文本；8 类策略 |
| 中文安抚/致歉话术 | CPED | 中文纯文本；`comfort` 806、`apology` 557 |
| 真实客服话术 | JDDC 2.1 | 需单位申请；无情绪标签、无音频 |

## 文件导航

- [`catalog.csv`](catalog.csv)：全部候选的机器可读清单，含语言、模态、规模、标签、获取方式、许可和优先级。
- [`zh-speech-emotion.md`](zh-speech-emotion.md)：中文带语音情绪语料的详细说明、获取步骤和推荐组合。
- [`text-support.md`](text-support.md)：ESConv、CPED 等纯文本辅助资源的统计和使用边界。

优先级含义：

- `A`：可获取且与对话情绪最相关，优先试用。
- `B`：可用，但需要适配或主要用于评测。
- `C`：仅作参考、需申请、语言不匹配或不满足当前筛选条件。
- `A-aux`：非语音辅助资源，用于策略、话术或文本情绪。

## 原始数据规则

- 本目录**只提交清单、说明和核实记录**，不提交 `wav`、`mp3`、`mp4`、`zip`、原始 CSV/JSON 等数据文件。
- 下载目录统一用 `data/datasets/<数据集名>/`；`data/` 已被仓库忽略，不会误入 Git。
- gated、需签 License、CC BY-NC、CC BY-NC-ND 或来源为影视剧的数据，**不得再分发**；比赛和商用前必须复核。
- 每个数据集至少记录：官方入口、获取日期、许可、文件大小或哈希。拿不到授权就不要阻塞项目。

## 复核证据

- **ESConv**：`ESConv.json` HTTP 200，实测 9,017,487 字节；1,300 段对话、38,365 轮、18,376 条策略标注；`FailedESConv.json` 196 条。
- **CPED**：三个 CSV 合计 132,762 句、11,835 个对话、303 个唯一 `Speaker` 字符串；仓库没有音频文件。
- **EmotionTalk / M3ED / MER2023 / MER2024 / ESD / EMOVIE / CSEU-Bench**：2026-11-08 从官方仓库或数据页核对入口、规模、许可和获取方式，细节见 `zh-speech-emotion.md`。
- **未执行**：没有完整下载所有语料；没有验证 gated 申请是否通过；没有对许可做法律意见；没有用这些数据训练或评测模型。

## 新增数据集的检查清单

1. 先确认语言、模态、是否有音频、是否有情绪或对话行为标签。
2. 记录论文、官方仓库/数据页、许可和获取门槛。
3. 能直接下载的，下载到 `data/datasets/` 并记录大小/哈希；不能直接下载的，写清申请方式。
4. 更新 `catalog.csv` 和对应说明文档，不改动 baseline 业务代码。
5. 不把原始数据、申请邮件、企业资料或个人信息提交到 Git。
